# МАРШРУТ — этап 1: главная страница

Реализовано на базе структуры `karkunov.zip`, без перезаписи backend/CRM.

## Быстрый запуск (Windows / Node.js 22+)

1. Распаковать содержимое `marshrut-home-patch.zip` **в корень проекта `karkunov/`**, с заменой указанных файлов. В архиве нет дополнительной вложенной папки `karkunov`.
2. Открыть терминал в корне проекта.
3. Запустить `npm run preview`.
4. Открыть `http://127.0.0.1:4173/`.

Для этого локального предпросмотра `npm install`, `.env`, Prisma и база данных **не требуются**. Остановить сервер: `Ctrl+C`. Доступен только localhost.

## Добавленные файлы

- `public/index.html` — вся главная страница.
- `components/header.html`, `components/footer.html` — новые общие компоненты под бренд МАРШРУТ.
- `site/sass/home.scss` — исходные стили и SCSS-переменные оформления.
- `site/css/home.css` — готовая CSS-сборка для предпросмотра.
- `site/scripts/home.js` — сценарии формы, выбора машины/направления, модального окна, reveal.
- `site/img/*.webp` — **временные изображения, обрезанные из пользовательского референса**.
- `site/img/icons.svg`, `site/img/favicon.svg` — иконки и фавикон.
- `scripts/preview-public.js` — отдельный HTTP-сервер только для вёрстки.
- `package.json` — добавлен `npm run preview`, изменены name/description; остальные зависимости сохранены.
- `server.js` — изменён только путь главной страницы: `public/index.html` вместо корневого `index.html`.

## Что работает

- Адаптив (desktop/tablet/mobile), отдельное мобильное меню.
- Поля маршрута, даты и количества пассажиров.
- Выбор автомобиля и направления с прокруткой к форме.
- Модальное окно с резюме поездки, полями имени/телефона, закрытием.
- Плавные появления секций, интерактивные карточки, поддержка reduced motion.

## Ограничения текущего этапа

- **Заявки не отправляются!** Модальное окно сообщает об этом прямо. Существующий `/api/requests` относится к грузоперевозкам и не подключён к форме трансфера.
- Другие публичные HTML-страницы ещё не готовы. Навигация временно ведёт к секциям главной.
- Ветви backend/Prisma/CRM, SEO-сервис карточек автомобилей, robots/sitemap и deploy **не адаптированы под МАРШРУТ** — это следующие этапы.
- Изображения из макета **не являются подтверждёнными фотографиями автомобилей и направлений клиента**. Их необходимо заменить реальными полноразмерными фото до публикации.
- Указанные на макете направления, внешний вид и вместимость минивэнов необходимо согласовать с владельцем.
- Контактный телефон и домен сознательно не выдуманы и пока не указаны.

## Следующий этап после утверждения вёрстки

1. Заменить фото авто и hero, уточнить бренд-палитру.
2. Реализовать оставшиеся публичные страницы внутри `public/`.

4. Подключить форму к настоящему API и настроить уведомления.
